# Tamil Nadu SEZ Location Analysis

This repository contains a descriptive spatial analysis of operational Special Economic Zones (SEZs) in Tamil Nadu, India. The project constructs an SEZ point-location dataset, links it to district-level characteristics, compares SEZ and non-SEZ districts, and uses SHRUG VIIRS night lights for a district-year descriptive extension.

The analysis is descriptive, not causal. SEZ locations are manually geocoded from official administrative descriptions and should be interpreted as approximate point locations, not official SEZ boundaries.

## Main Components

- `Code/analysis.R`: Main R script for data construction, cleaning, mapping, summary tables, night-lights panel creation, and descriptive regression.
- `Data/processed/zones.csv`: Manually constructed dataset of 49 operational SEZs in Tamil Nadu, with locations, sectors, geocoding notes, and notification-date fields.
- `Data/processed/analysis_units.csv`: District-level analysis file for Tamil Nadu, including SEZ status, number of SEZs, distance to Chennai, coastal status, population density, and 2021 VIIRS night lights.
- `Data/processed/district_year_nightlights_panel.csv`: District-year panel using SHRUG VIIRS night lights and SEZ status at the 2011 Census district level.
- `Output/Tables/`: CSV tables for SEZ/non-SEZ comparisons, correlations, treatment-timing checks, and night-lights trends.
- `Output/Plots/`: PNG maps and figures generated by the analysis.
- `Report/memo.tex` and `Report/memo.pdf`: Written memo summarizing the data construction, descriptive findings, dynamic extension, limitations, and AI disclosure.

## Data Sources

The project uses and documents the following source inputs:

- SEZ India operational SEZ list
- SEZ India notified SEZ list
- Manual public map search for approximate SEZ coordinates
- SHRUG VIIRS annual night lights
- GADM district boundaries
- District-level population density and manually coded spatial characteristics

Source metadata and limitations are recorded in `Data/processed/sources.csv`.

## Reproducing the Analysis

Run the main analysis script from the repository root:

```r
source("Code/analysis.R")
```

Note: the checked-in script is `Code/analysis.R`, but its `here::i_am()` root marker currently references `Code/code.R`. If rerunning the project from a fresh clone, make sure that marker matches the script filename used in your local checkout before sourcing the file.

The script expects the raw SHRUG VIIRS Stata file at `Data/raw/viirs_annual_pc11dist.dta` and uses GADM district boundaries through `geodata::gadm()`. Processed data, tables, and plots are written back into the existing `Data/processed/`, `Output/Tables/`, and `Output/Plots/` folders.

Required R packages:

```r
install.packages(c(
  "tidyverse",
  "readr",

```

To rebuild the memo PDF from LaTeX:

```bash
latexmk -pdf Report/memo.tex
```

## Notes and Limitations

- SEZ coordinates are approximate and manually assigned from administrative location text.
- Official SEZ GIS boundaries were not available.
- Some Tamil Nadu districts were created after the 2011 Census, so district-level night-light matching uses a current-district-to-2011-district crosswalk.
- Notification dates are used as a rough proxy for SEZ timing where available; they may differ from operational start dates.
- The night-lights extension compares SEZ and non-SEZ districts descriptively and should not be interpreted as a causal estimate of SEZ effects.
